# Weather App — приложение погоды на Open-Meteo API

Минималистичный сайт погоды: введите город и получите текущую погоду и прогноз на 5 дней.
Проект написан на чистых HTML, CSS и JavaScript — без фреймворков, сборщиков и API-ключей.

## Возможности

- Поиск города по названию (на русском или английском)
- Текущая температура, состояние погоды, «ощущается как», влажность и скорость ветра
- Прогноз на 5 дней: максимум и минимум температуры
- Адаптивная вёрстка (mobile-first): телефон, планшет, компьютер
- Светлая и тёмная тема — подстраивается под настройки устройства
- Понятные сообщения: загрузка, «город не найден», «нет интернета»

## Технологии

- HTML5, CSS3 (Flexbox, Grid, CSS-переменные)
- JavaScript (`fetch`, `async/await`)
- [Open-Meteo API](https://open-meteo.com/) — бесплатный API погоды без регистрации и ключа

## Установка и запуск

Нужны только браузер и интернет. Устанавливать ничего не нужно.

1. Скачайте проект:
   ```bash
   git clone https://github.com/<ваш-логин>/weather-app.git
   cd weather-app
   ```
   Или нажмите **Code → Download ZIP** на странице репозитория и распакуйте архив.
2. Откройте `index.html` двойным кликом.

Другие способы запуска:

- VS Code → расширение **Live Server** → кнопка **Go Live**
- Терминал: `python -m http.server 8000`, затем откройте http://localhost:8000

## Как работает API

**API** — способ, которым одна программа запрашивает данные у другой. Сайт отправляет запрос (обычную ссылку с параметрами), а сервер возвращает ответ в формате JSON — текст со структурированными данными.

Приложение делает два запроса:

1. **Геокодинг** — название города → координаты
   ```text
   https://geocoding-api.open-meteo.com/v1/search?name=London&count=1&language=ru
   ```
2. **Прогноз** — координаты → погода
   ```text
   https://api.open-meteo.com/v1/forecast?latitude=51.5&longitude=-0.12&current=temperature_2m&daily=temperature_2m_max&timezone=auto
   ```

Любую ссылку можно вставить в адресную строку браузера — вы увидите JSON-ответ. В `script.js` запрос отправляет `fetch()`, после чего нужные поля (`temperature_2m`, `weather_code` и др.) выводятся на страницу.

Документация: https://open-meteo.com/en/docs

> Open-Meteo бесплатен для некоммерческого использования (до ~10 000 запросов в сутки). Ссылка на источник данных в футере сайта обязательна.

## Публикация на GitHub

1. Создайте на github.com новый пустой репозиторий `weather-app` (без README).
2. В папке проекта выполните:
   ```bash
   git init
   git add .
   git commit -m "Add weather app"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/weather-app.git
   git push -u origin main
   ```
3. По желанию включите сайт онлайн: **Settings → Pages → Branch: main / (root) → Save**.
   Через минуту сайт откроется по адресу `https://<ваш-логин>.github.io/weather-app/`.
